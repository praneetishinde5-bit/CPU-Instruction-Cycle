# CPU Instruction Cycle Simulator (COA Micro-Project)

A web-based interactive simulator demonstrating the core **CPU Instruction Cycle (Fetch, Decode, Execute)** developed for the Computer Organization and Architecture coursework at Sanjivani University.

* **Name:** Praneeti Pramod Shinde

* **Topic:** CPU Instruction Cycle (Fetch, Decode, Execute)

---

## 🚀 Features & Customisation
* **Adjustable Parameters:** Users can customize input numbers, choose between addition and subtraction operations, and select between different programs (*Add/Subtract* or *Add Three Numbers*).
* **Step-by-Step Execution:** Manual step-through controls (Next/Back) or Auto-play mode with adjustable speeds.
* **Detailed Register Inspection:** Toggleable detailed mode to inspect internal CPU registers (`PC`, `IR`, `MAR`, `MDR`, `ACC`) and step-by-step micro-operations (`F1–F4`, `E1–E3`).
* **Visual Data Flow:** Animated data-movement chips illustrating bus communication between memory and the CPU.

---

## 🛠️ Tech Stack & Design
* **HTML5 / CSS3:** Modern responsive UI design utilizing CSS flexbox/grid and custom design variables.
* **Vanilla JavaScript:** Clean, modular engine managing state snapshots, instruction decoding, and UI synchronization.
